title: On running LLMs locally
date: 2026-04-08
---
The current state of open models is such that you can’t run a good-enough model on an average laptop/PC.

The only open model that is intelligent enough and can run on consumer-grade hardware is Gemma 4 31B IT. There are small Gemma 4 models, but they are not good for tasks that require reasoning and precision. There are intelligent and open models from other companies but they don’t run on consumer-grade hardware. So, Gemma 4 31B IT seems like the only option left.

But what does consumer-grade even mean here? Which laptop do you need to buy to run Gemma 4 31B IT?

The cheapest laptop/PC that can run Gemma 4 31B IT with a long context window and other concurrent apps is the Mac Mini Pro or MacBook Pro with at least 64GB RAM. Search for their prices in your location; this is the cheapest option.

To conclude: If you are an average person like me, doing average tasks on an average laptop, you can’t run any good models locally.

However, you can get a free Gemma 4 API key from aistudio.google.com. The free tier of Google AI Studio is generous enough that you can’t use all the free tokens -- unless you need the API for programming-related tasks.
